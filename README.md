# 🏠 TrouveTonNid App

Application web de recherche immobilière permettant de trouver des biens à acheter ou louer avec filtres (ville, prix, type).

---

## 🚀 Stack

* React
* Node.js / Express
* MongoDB
* JWT Auth

---

## ⚙️ Fonctionnalités

* Recherche de biens
* Filtres (ville, prix, type)
* Page détail d’un bien
* Authentification utilisateur

---

## ▶️ Installation

### Backend

```bash
cd api
npm install
npm start
```

### Frontend

```bash
cd client
npm install
npm run dev
```

---

## 🔐 .env

```env
MONGO_URI=your_mongo_uri
JWT_SECRET_KEY=your_secret
```
